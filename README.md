# מעבדת הדופק והנשימה

כלי לימודי (עברית, RTL, mobile-first) לתלמידי מדעי הבריאות והביולוגיה בתיכון. התלמידים מודדים דופק וקצב נשימה, מתעדים מצבים שונים, משווים בין מדידות ופרופילים, מבצעים אתגר התאוששות מודרך, ומכירים המחשות של קצבי לב — הכול בדפדפן, בלי שרת ובלי חשבונות.

**פותח על ידי אורי העליון.**

> יישום זה נועד ללמידה ולהתנסות פדגוגית בלבד. הוא אינו מכשיר רפואי, אינו מיועד לאבחון ואינו תחליף לייעוץ רפואי.

## מה הכלי עושה

| מסך | תיאור |
|---|---|
| **למדוד עכשיו** | בחירת פרופיל ומצב (מנוחה, אחרי מאמץ, התאוששות וכו'), מדידת דופק ואז נשימה, כרטיס תוצאות ושמירה |
| **אתגר ההתאוששות** | בסיס במנוחה ← פעילות מותאמת ← מדידה מיד אחרי ← מדידות חוזרות בהתאוששות ← סיכום עם גרפים והפרשים מהבסיס (או דוגמה בנתוני הדגמה) |
| **התיקים שלי והשוואות** | פרופילים, היסטוריה עם סינון, השוואות (עמודות, קווי זמן, שני צירים), ייצוא/ייבוא JSON, CSV, הפקת דוח PDF |
| **לגלות וללמוד** | גלריית המחשות קצב עם טיק ופסי פעימות (ללא אק״ג), השוואה "המדידה שלי מול המחשה", הסברים קצרים |
| **איך משתמשים?** | מדריך לתלמיד ומדריך למורה (נערכים בקובצי JSON) |
| **פרטיות ובטיחות** | ההצהרה הרפואית הקבועה, הסבר על הנתונים, מחיקה מלאה |

### שיטות המדידה

- **דופק — מצלמה (PPG):** אצבע על עדשת המצלמה האחורית. ניתוח פריימים מקומי ב-canvas, איתור פעימות, בדיקות איכות (כיסוי עדשה, קצב פריימים, יציבות מרווחים, מחזוריות). אם האות אינו אמין — "המדידה לא הצליחה" ולא נרשם ערך.
- **דופק — ספירה ידנית:** שעון עצר 30/60 שניות, או הקשה בכל פעימה (מתועד כ"הקשות משתמש").
- **נשימה — מיקרופון (ניסיוני):** מעטפת האנרגיה של רעש הנשימה בתחום 200–2000Hz; אם יש דיבור/רעש או שאין אות — "התוצאות לא התקבלו היטב — כדאי לנסות שוב במקום שקט".
- **נשימה — ספירה ידנית:** שעון עצר והזנת מספר (הקשות כחלופה משנית).

כל מדידה נשמרת עם מקור (`measured_camera`, `measured_microphone`, `measured_manual`, `counted_manual`, `demo_simulated`) ואיכות. מדידות אמיתיות והדגמות אינן מתערבבות בלי סימון בולט.

## פרטיות

- הנתונים נשמרים ב-`localStorage` של הדפדפן במכשיר בלבד. אין שרת, אין ניתוח, אין שליחה.
- מצלמה ומיקרופון נפתחים רק אחרי לחיצה, ומשוחררים בסיום, בעצירה, במעבר מסך ובסגירת הדף. לא נשמרים תמונה או קול — רק מספרים.
- חובה רק כינוי. גיל, מין ורקע רפואי אופציונליים, ואינם נכללים בייצוא או ב-PDF אלא בבחירה מפורשת.
- אין פונקציות כיתתיות: אין איסוף מדידות, חשבונות מורים או השוואות בין תלמידים. שיתוף נעשה רק ביוזמת המשתמש.

## הרצה מקומית

דרוש Node.js 18+ (רק לשרת סטטי קטן; אין תלויות ואין build).

```bash
node tests/serve.mjs 8080
```

ואז לפתוח `http://localhost:8080/`. כתובת `localhost` נחשבת "הקשר מאובטח", ולכן מצלמה ומיקרופון פועלים. אי אפשר לפתוח את `index.html` ישירות כקובץ (`file://`), כי קובצי התוכן נטענים ב-`fetch` ומודולי JS דורשים שרת.

לבדיקת הנתיב ב-GitHub Pages (תחת שם ה-repository):

```bash
node tests/serve.mjs 8081 /pulse-breath-lab/
```

בדיקות אוטומטיות של עיבוד האות והאחסון:

```bash
npm test
```

## עריכת תוכן

כל ההסברים (מדריך תלמיד, מדריך מורה, כרטיסי הקצבים, הסברים קצרים, פרטיות) נמצאים ב-`content/he/*.json`. אפשר לשנות ניסוח או להוסיף פריט בלי לגעת בקוד. ההצהרה הרפואית המחייבת והקרדיט נמצאים ב-`js/constants.js`.

## מגבלות ידועות

- **PPG במצלמה אינו מובטח בכל טלפון/דפדפן.** שליטה בפנס (`torch`) נתמכת בעיקר ב-Chrome באנדרואיד; ב-iOS Safari לרוב אין שליטה בפנס, ויש למדוד באור חזק. כשהאיכות נמוכה האפליקציה מסרבת לרשום ערך ומציעה ספירה ידנית.
- **מיקרופון לנשימה ניסיוני.** רגיש לדיבור, לרוח, לרעש רקע ולמרחק; ייתכן שבמכשירים מסוימים ביטול הרעש/AGC אינו ניתן לכיבוי ויפגע בזיהוי. הספים כוונו על אותות סינתטיים (ראו TESTING.md) ועדיין לא אומתו בשטח.
- **PPG אינו אק״ג.** אין זיהוי הפרעות קצב, ואין תרשימי אק״ג בשום מקום ביישום.
- **דוח PDF** נוצר באמצעות הדפסה מעוצבת (A4, RTL, גופני מערכת) ובחירה ב"שמירה כ-PDF" בחלון ההדפסה של הדפדפן. אין ספריית PDF; לכן ״שיתוף״ ישיר של קובץ PDF אינו אפשרי — אפשר לשמור את ה-PDF ולשתף אותו מהמכשיר, או להוריד/לשתף קובץ HTML של הדוח.
- נתונים שמורים ב-`localStorage`; ניקוי נתוני האתר או גלישה פרטית ימחקו אותם — מומלץ לייצא גיבוי.
- אין עדיין מצב offline (Service Worker) ואין התקנה כ-PWA.
